# AI 终端启动器 — 使用说明

## 1. 安装

在本仓根目录：

```bash
chmod +x scripts/build.sh
./scripts/build.sh
```

完成后 Dock 出现「AI终端启动器」，安装路径 `~/Applications/AI终端启动器.app`。
改名前的 `AI启动器菜单栏.app` 会在构建成功后自动移入废纸篓，不影响 `~/.config/ai-launcher/config.json`。
若之前把旧图标固定在 Dock，重新拖一次新图标即可（旧固定项指向已移除的路径）。

## 2. 配置

路径：`~/.config/ai-launcher/config.json`

对照根目录 [config.example.json](../config.example.json)：

| 字段 | 含义 |
|------|------|
| `dirs` | 启动网格里的项目绝对路径 |
| `tools[].name` | 按钮文字 |
| `tools[].cmd` | 实际命令（需已在 PATH，或能被 `pathPrepend` 里的目录找到） |
| `pathPrepend` | 启动脚本注入到 PATH 前面的目录，缺省 `["~/.bun/bin", "/opt/homebrew/bin", "/usr/local/bin"]`；写 `[]` 表示不注入，改用登录 shell 自带 PATH |
| `copy.hosts` | 互拷「预设」下拉的主机列表（显示名 + `user@host`），选中即填连接串/用户名/主机 |
| `copy.defaultFlags` | 追加到 rsync/scp 的额外参数 |

以下两个旧字段已废弃，写了也会被忽略（兼容老配置，不必删除）：`copy.defaultDirection`（方向改由路径自动推导）、`copy.auth`（密码走 Terminal 真 TTY 交互，不存标记）。

改完保存，回到窗口点「刷新」。刷新会保留已填的互拷表单。不要把填了真实主机的 JSON 拷进本仓。

## 3. 启动 CLI

- 点某一行的 `opencode` / `omp`：Terminal 新窗口进入该目录并启动
- 「其他目录」：选 CLI →「选择目录并启动」
- 退出应用：菜单「退出 AI 启动器」或 `⌘Q`。只关窗口不会退出，点 Dock 图标可找回
- 项目多时窗口出现滚动条，也可直接拖窗口边缘放大（最小 480×320）

## 4. 互拷

1. 源、目标填本地绝对路径，或 `user@host:path`
2. 也可在连接串粘贴 `user@host`、`user:pass@host`、表格里的 `IP<TAB>用户/密码`，点「解析」填凭据字段
3. 「预设」下拉（来自 `copy.hosts`）选中即填连接串与凭据；也可在源/目标/连接串/IP 框输入片段，停顿后弹出候选（↑↓ 选择、回车/Tab 采用、Esc 取消），会按当前框填前缀
4. 「选择…」用本机文件面板；「浏览远端」需先有主机信息且该机已免密
5. 勾选递归 / 保留属性 / 断点续传后点「开始拷贝」
6. 看 Terminal 的 `===== 开始拷贝 =====` 与退出码；成功会自动关闭这次拷贝所在的 Terminal 窗口

### 浏览远端（可逐层导航）

点「浏览远端」→ 填起始路径（默认 `~`）→「列出」后弹出的对话框里：

| 按钮 | 作用 |
|------|------|
| 选为路径 | 把当前目录写进源/目标框（`user@host:目录`） |
| 进入下一层 | 选中列表中带 `/` 结尾的目录，继续往下列 |
| 上一级 | 回到父目录（`~/a/b` → `~/a`，`/a` → `/`） |
| 取消 | 结束浏览 |

每次列目录都在后台线程执行，等待期间窗口不会卡住。

### 服务器↔服务器（直拷与中转）

- 「开始拷贝」：在**源机**上执行 rsync 直推目标机，要求源机有 `rsync` 且能 ssh 到目标机
- 「经本机中转」：直拷失败时的兜底，按「断点续传」是否勾选走两种实现：

| 模式 | 触发条件 | 命令形态 | 断点续传 | 本地磁盘 |
|------|----------|----------|----------|----------|
| 续传式中转 | 勾选「断点续传」且本机有 rsync | 两段 rsync：源机 → 本机暂存 → 目标机 | **支持**：中断后再点一次同一任务即从断点继续 | 占（约一份源数据） |
| tar 流中转 | 未勾选，或本机没有 rsync | `ssh 源机 tar -cf - \| ssh 目标机 tar -xf -` | 不支持，中断要重来 | 不占 |

- 续传模式的暂存目录固定为 `~/Library/Caches/ai-launcher/relay/<源文件名>-<哈希>`，同一对源/目标永远落到同一个目录，所以重跑才能接上；中转成功后会删掉该目录，失败时保留以便下次续传。要手动清空：`rm -rf ~/Library/Caches/ai-launcher/relay`
- 半截文件放在目标侧的 `.rsync-partial` 目录里，rsync 以它为基底做增量，比 `--append-verify` 安全（目标文件被改短时不会写坏）
- 两端都可能要输密码时，中转要输两次（先源机、后目标机）

密码不会写入命令。未免密时，在弹出的 Terminal 里按 ssh 提示输入。

### 非 22 端口与 IPv6

- 非 22 端口：路径框可写 `user@host:2222:/path`（或解析连接串时在端口框填 2222），rsync 自动转 `-e "ssh -p 2222"`、scp 转 `-P 2222`
- IPv6：用方括号写法，如 `user@[::1]:2222:/data`；裸地址（`::1`）可以填在主机框，但**带路径时必须加方括号**，否则无法区分端口和路径

## 5. 排障

| 现象 | 处理 |
|------|------|
| 点按钮没反应 | 看 `/tmp/ai-launcher-debug.log`；确认 Terminal 是默认打开 `.command` 的应用 |
| CLI 报 command not found | 改 `tools[].cmd` 为绝对路径，或把目录加进 `pathPrepend` 后点刷新 |
| 远端浏览失败 | 先 `ssh user@host` 确认免密；`BatchMode` 不会弹出密码 |
| 远端浏览卡住 | ssh 在后台线程执行，状态栏显示「正在列出远端目录…」；超过 10 秒未回多半是网络不通 |
| 直拷失败 | 登录源机确认有 `rsync`、能 ssh 到目标机；或用「经本机中转」 |
| 中转失败 | 目标机路径要能创建（有写权限）；两端各需能 ssh 登录 |
| 中转中断后想接着传 | 保持「断点续传」勾选、源/目标不变，再点一次「经本机中转」；暂存目录名由源+目标哈希决定，路径一变就是新任务 |
| 中转占满本地磁盘 | 续传模式会占约一份源数据的空间；改不勾「断点续传」走 tar 流，或清 `~/Library/Caches/ai-launcher/relay` |
| 拷贝完 Terminal 没自动关 | 关窗按 tty 精确匹配当前 tab，匹配不到就不关（避免误关别的窗口），手动关即可 |
| 拷贝成功但按时间找不到文件 | rsync `-a` 保留源 mtime，按修改时间排序会靠前/靠后，按文件名搜 |
| 提示「已降级 scp」 | 本机没装 rsync；scp 不支持断点续传，装上 rsync 即可恢复 |

日志里连接串与密码均已脱敏（只记 user/host/port 与密码是否存在），可以放心贴出来排障。
