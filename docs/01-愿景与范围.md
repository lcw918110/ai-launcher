# AI 终端启动器 — 愿景与范围

本文说明产品定位与范围，不作操作指南。使用见 [04-使用说明.md](04-使用说明.md)，要求见 [02-需求规格.md](02-需求规格.md)，当前缺口见 [06-已知缺口与后续.md](06-已知缺口与后续.md)。

## 1. 产品定位

本机 **macOS Dock 窗口应用**：把常用项目目录和 CLI（目前主要是 `opencode`、`omp`）摆成按钮网格，点一下就在 Terminal 新窗口里启动。同一窗口提供本机与服务器、服务器与服务器之间的文件/文件夹互拷。

它是单用户、单机工具，不为多租户或远程桌面设计。配置在用户主目录，安装产物在 `~/Applications`。

## 2. 典型场景

- 在几个固定仓库目录间切换，分别打开 OpenCode 或 Oh My Pi
- 临时选一个未列入配置的目录启动同一套 CLI
- 把本机文件推到内网服务器，或从服务器拉回本机
- 在两台已互通 SSH 的服务器之间直拷（到源机执行 rsync，避免本机中转）

## 3. 干系人

| 角色 | 诉求 |
|------|------|
| 本人（日常使用） | 少点几次、少记路径，目录和 CLI 可改配置而不重编译 |
| 接手人 | 源码、文档、安装产物、本机配置四者边界清楚，能独立编译 |

## 4. 范围

**做：**

- 从 JSON 配置读取目录列表与 CLI 列表，窗口即时刷新
- 用临时 `.command` + `open` 启动 Terminal，不申请辅助功能（TCC）自动化授权
- 互拷：多格式连接串解析、方向自动推导、rsync（无则 scp）、进度窗口、成功后自动关窗
- 从 `~/.ssh/config` 读免密主机并做输入联想；密钥模式下用 `ssh ls` 浏览远端目录

**不做：**

- 非 macOS
- 菜单栏常驻图标（现行形态是 Dock 窗口，2026-10-29 已把名称里的「菜单栏」去掉）
- 把 SSH 密码写入配置、命令行或 `.command` 文件
- 云端同步配置、自动更新、代码签名分发
- 完整 IPv6 地址解析（现支持方括号写法与裸地址填主机框，不做 `%iface` 校验）
- 把本机真实 `config.json` 或私钥纳入本仓

## 5. 成功标准

- 本机可 `./scripts/build.sh` 产出可打开的 `.app`
- 改配置点刷新后按钮与互拷预设立即变化
- `./scripts/test.sh` 的 181 条 Core 断言全通过（解析、转义、命令拼装、配置、免密主机、启动脚本、远端导航）
