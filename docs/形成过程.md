# 形成过程

本文只记沿革。现行用法见根 [README.md](../README.md) 与 [04-使用说明.md](04-使用说明.md)。

## 时间线

1. **菜单栏 AppleScript**  
   最初用菜单栏驻留，点项目目录在 Terminal 开 CLI。依赖系统事件，稳定性与授权成本高。

2. **Swift 菜单栏应用**  
   改为 Swift/AppKit，包名仍为 `local.ai-launcher.menubar`。目录与 CLI 一度写死在源码。

3. **Dock 窗口 + JSON 配置**  
   菜单栏点击不可靠后，改成常驻 Dock 的窗口网格。配置外置到 `~/.config/ai-launcher/config.json`，点刷新重读。启动改为写临时 `.command` 再 `open`，不再申请 Terminal 自动化授权。

4. **互拷**  
   增加本机↔服务器、服务器↔服务器拷贝：rsync 优先、scp 降级、进度在 Terminal、成功关窗。连接串兼容 `user@host` 与表格「IP + 用户/密码」。密码不进命令行。

5. **免密主机**  
   矿山 AI 虚拟机与固定资产约 25 台做完 `ssh-copy-id` 后，从 `~/.ssh/config` 联想补全；解析不再自动改路径框，以免源/目标串填。远端浏览用 `ssh ls`（仅密钥）。周报 2026-10-25 记录了这一段能力。

6. **独立仓（2026-10-29）**  
   源码从 `~/Applications/AI启动器菜单栏-src/` 迁到 `~/Desktop/git/ai-launcher`。`.app` 留在 Applications；真实配置不进 Git。文档按 01–07 编号补齐愿景、需求、架构、使用、测试、现状、交接。
