# AI 终端启动器 — 需求规格

现行功能以 `src/Core.swift`（逻辑）+ `src/main.swift`（UI）为准。使用步骤见 [04-使用说明.md](04-使用说明.md)。

## FR-1 配置驱动的启动网格

- 配置路径固定为 `~/.config/ai-launcher/config.json`
- `dirs`：绝对路径数组，窗口每行显示该路径最后一级目录名
- `tools`：`name`（按钮文字）与 `cmd`（实际命令）数组
- 每个目录对每个 CLI 生成一个按钮；点按钮后 `cd` 到该目录并 `exec` 该命令
- 启动前按 `pathPrepend`（缺省 `["~/.bun/bin", "/opt/homebrew/bin", "/usr/local/bin"]`）注入 `PATH`；写 `[]` 表示不注入
- 文件不存在时，应用按源码内置缺省创建配置（占位路径 + 缺省 `pathPrepend`，不含任何本机/内网信息）

## FR-2 其他目录启动

- 提供「其他目录」行：下拉选择 CLI，再弹出目录选择面板
- 只选目录、不选文件

## FR-3 刷新

- 「刷新」重新读配置并重建窗口，不退出进程；已填的互拷表单内容保留

## FR-4 免授权启动 Terminal

- 把命令写入 `NSTemporaryDirectory()` 下 `ai-launcher-<uuid>.command`，权限 `0755`，`open` 该文件
- 脚本先记 `_tty=$(tty)`，供成功后精确关窗
- 一次性任务（拷贝）成功且退出码 0 时，约 2 秒后只关闭该 tty 所在 Terminal 窗口；匹配不到则不关
- 超过一天的旧 `.command` 在下次启动时清理
- 不使用 System Events / 辅助功能去操作 Terminal

## FR-5 互拷

- 源、目标各自为本地绝对路径或 `user@host:path`（或 `host:path`）
- 方向由路径自动推导：`push` / `pull` / `direct`（两台远端） / `local`（两台本机）
- 选项：递归、保留属性（rsync `-a`）、断点续传（`--partial --partial-dir=.rsync-partial`，三条路径一致）、限速（MB/s，留空不限）
- 限速换算：rsync `--bwlimit=MB×1024`（KiB/s），scp 降级 `-l=KiB/s×8`（Kbit/s）；非法输入必须报错，不静默当不限速
- 断点续传的中断现场只落在目标侧 `.rsync-partial/`，最终路径不出现残缺文件；重跑同一任务即增量补齐
- 本机有 `rsync` 用 rsync 并带 `--info=progress2`；没有则 `scp`（状态栏提示断点续传不可用）
- 日志：`~/Library/Logs/ai-launcher/<源名>-<哈希>.log`，rsync `--log-file` 写明细，脚本记开始/结束与退出码；同一任务多次运行追加到同一文件
- 上次任务：`~/.config/ai-launcher/last-copy.json` 记录源/目标/选项，启动时表单为空则回填；不存密码
- 服务器↔服务器：`ssh -t` 到源机执行 rsync；另有「经本机中转」按钮以 tar 流兜底（不依赖源机 rsync）
- `copy.hosts` 作为互拷「预设」下拉展示，选中填连接串/用户名/主机；`defaultFlags` 追加到命令
- `defaultDirection`、`auth` 为废弃键，仅为兼容旧配置而忽略
- 密码框只作占位：认证在 Terminal 真 TTY 里由 ssh 交互，或依赖已装公钥

## FR-6 连接串解析

支持：

1. `user@host`、`user:password@host`、`ssh://…`、`host`、`user@host:port`、`host:port`
2. 主机在前（表格复制常见）：`host<TAB|空格|:|,|;|\|>user/pass`
3. IPv6 方括号写法：`user@[::1]:2222`、`[::1]:2222`

解析结果回填用户名 / 密码 / IP / 端口四个字段，**不**自动改源、目标路径（避免串框）。

## FR-7 免密主机联想与远端浏览

- 读 `~/.ssh/config` 的 `Host` / `HostName` / `User`，跳过含 `*` 或 `?` 的通配
- 输入不少于 2 个字符、停顿 0.15 秒后，用非阻塞 `NSPopover` 弹出最多 10 条匹配（不抢键盘焦点）
- 键盘：`↑`/`↓` 移动、`Enter`/`Tab` 采用、`Esc` 收起；也可直接点击
- 选中后按触发框填 `user@host` 或 `user@host:` 前缀，并补空的 IP、用户名
- `~/.ssh/config` 修改后（mtime 变化）下次输入自动重载，无需重启
- 「浏览远端」用 `ssh -o BatchMode=yes` 执行 `ls -1p`，仅密钥可用；支持逐层「进入下一层 / 上一级 / 选为路径」，全程后台线程执行；失败时提示改手填

## FR-8 测试入口

- `./scripts/test.sh`：Core 纯逻辑断言 181 条（解析、转义、命令拼装、配置读写、免密主机、启动脚本语法、远端导航），无 GUI 副作用，失败返回非 0，可进 CI
- 命令行带 `--selftest`：启动后约 1 秒做窗口/控件检查并模拟点击第一个启动按钮，约 5 秒后退出（GUI 冒烟，不含回归断言）
- `--selftest --no-launch`：同上但不点启动按钮、不弹 Terminal
- 日志：`/tmp/ai-launcher-debug.log`（连接串与密码已脱敏）

## 非功能

- 关窗口不退出进程，点 Dock 图标可再打开
- `⌘Q` 退出
- 窗口内容可滚动、可缩放（最小 480×320），初始高度不超过屏幕可用高度
- 最低系统版本 macOS 13（`Info.plist` `LSMinimumSystemVersion`）
