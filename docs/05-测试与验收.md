# AI 终端启动器 — 测试与验收

分两层：**Core 纯逻辑测试（可进 CI，无副作用）** + **GUI 冒烟/手工验收**。

## 1. 目录

| 文件 | 职责 |
|------|------|
| `src/Core.swift` | 纯逻辑层（仅 Foundation）：连接串解析、路径/主机拆分、shell 转义、命令拼装、配置读写、`~/.ssh/config` 解析 |
| `src/main.swift` | UI 层（AppKit）：窗口、按钮、弹窗、Terminal 启动 |
| `tests/main.swift` | Core 全量断言用例（纯命令行） |

## 2. Core 测试（默认入口）

```bash
./scripts/test.sh
```

等价于 `swiftc -O src/Core.swift tests/main.swift -o /tmp/ai-launcher-core-tests && /tmp/ai-launcher-core-tests`。
无 GUI、不弹 Terminal，失败返回非 0，可直接进 CI（`.github/workflows/ci.yml`）。

覆盖范围（124 条断言）：

| 组 | 覆盖点 |
|----|--------|
| `looksLikeHost` | IP / 域名 / 含 `@`、`:`、空串 |
| `parseConnection` | `user@host`、`user:pass@host`、`ssh://` 前缀、`host:port`、纯 IP/域名、**`IP:端口` 不当用户名（回归）**、表格「主机在前」的 Tab/空格/冒号/竖线/逗号五种分隔、密码含 `@`、空串 |
| `splitHostPort` / `buildHostSpec` | 有无端口、`user@host:port` |
| `splitRemotePath` / `splitRemoteSpec` | `host:path`、`host:port:path` 拆分（端口与路径都要对） |
| `shellQuote` / `remotePathArg` | 空格、单引号、**`~` 必须裸写否则远端 `ls` 找不到目录（回归）** |
| `maskSecret` | 日志脱敏 |
| `deriveDirection` | push / pull / direct / local |
| `buildCopyCommand` | push/pull/direct/local 全选项拼装、**自定义端口走 `-e "ssh -p N"` / `scp -P N`（回归）**、双远端双端口、路径含空格引号 |
| `buildFillPlan` | 六场景（目标框触发不串到源框） |
| 配置读写 | 合法 JSON、损坏 JSON 回退缺省、废弃键兼容、`ensureConfigExists` 不覆盖已有、**缺省配置不含本机路径/内网主机（回归）** |
| `loadSSHKnownHosts` | 跳过 `Host *`、HostName 覆盖别名、文件不存在 |
| `sshListDir` | 不可达主机优雅失败（带错误信息） |

## 3. 编译检查

```bash
swiftc -O src/Core.swift src/main.swift -o /tmp/ai-launcher-check
file /tmp/ai-launcher-check
```

期望：Mach-O 可执行文件，退出码 0。这条不覆盖安装产物、也不杀正在跑的 `.app`。
安装路径验收用 `./scripts/build.sh`（会重启已打开的启动器）。

## 4. GUI 冒烟 `--selftest`（可选）

```bash
/tmp/ai-launcher-check --selftest
```

会真正启动窗口，1 秒后模拟点击第一个启动按钮（可能弹出 Terminal 跑配置里的第一个 CLI），断言互拷控件已构建，约 5 秒后自动退出。日志 `/tmp/ai-launcher-debug.log`。

纯逻辑断言已全部迁到 `tests/main.swift`，`--selftest` 不再承载回归职责，只做界面链路冒烟。**不要在无人值守环境默认跑**（会弹 Terminal）。

## 5. 手工验收（P0）

| 项 | 操作 | 期望 |
|----|------|------|
| 网格启动 | 点某个目录的 opencode | Terminal 工作目录为该路径 |
| 刷新 | 改 `dirs` 后点刷新 | 行数与名称变化，且互拷表单已填内容不丢 |
| 本机→远端 | 小文件 push | 远端出现文件，成功关窗 |
| 解析 | 粘贴 `user@host` 点解析 | 用户名与 IP 回填，路径框不变 |
| 解析（端口） | 粘贴 `192.168.1.5:2222` 点解析 | 主机框 `192.168.1.5`、端口框 `2222`，用户名框为空 |
| 联想 | 输入已配置免密 IP 的前几位 | 弹出列表，选中填对应框 |
| 浏览远端 | 点「浏览远端」直接「列出」 | 状态栏「正在列出…」→ 弹出目录列表（默认 `~`） |
| 非 22 端口拷贝 | 目标 `user@host:2222:/path` | Terminal 里 rsync 带 `-e "ssh -p 2222"` |
