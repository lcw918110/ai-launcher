# AI 终端启动器 — 已知缺口与后续

本文是**现状与缺口**，不替代 [04-使用说明.md](04-使用说明.md)。待办未做不等于已经解决。

## 当前结论

- 日常启动 CLI 与互拷已在本机使用：窗口网格、配置刷新、`.command` 启 Terminal、rsync/scp、连接串解析、免密联想、远端 `ls` 点选。
- 源码分两层：`src/Core.swift`（纯逻辑，Foundation only）+ `src/main.swift`（AppKit UI）。
- Core 有 124 条命令行断言（`./scripts/test.sh`，无 GUI 副作用），并有 GitHub Actions CI；`--selftest` 仅做 GUI 冒烟。
- 源码从 `~/Applications/AI启动器菜单栏-src/` 迁到本仓；`.app` 仍在 Applications；真实配置仍在 `~/.config/ai-launcher/`。
- 周报 2026-10-25 已记录互拷与约 25 台免密主机。现行 `config.json` 的 `copy.hosts` 只保留少量预设，完整主机清单在 `~/.ssh/config`，不进本仓。

## 已交付（对照源码，不是历史口号）

| 项 | 现状 |
|----|------|
| 目录 × CLI 启动 | `loadConfig` + 按钮 `launchTool` |

| 可测逻辑层 | `src/Core.swift` + `tests/main.swift` + `scripts/test.sh` + CI |


## 已知缺口

| ID | 缺口 | 影响 | 建议 |
|----|------|------|------|
| G-1 | ~~无独立测试靶~~ **已解决** | `tests/main.swift` 124 条断言 + `scripts/test.sh` + CI；`--selftest` 仅 GUI 冒烟 | — |
| G-2 | ~~`defaultConfigJSON()` 写死本机路径与内网主机~~ **已解决** | 缺省改为 `/path/to/...` 占位，测试断言不含本机路径 | — |
| G-3 | 包名与产品名仍带「菜单栏」，实际是 Dock 窗口 | 交接时易按菜单栏去找 `LSUIElement` | 更名需改 bundle id、`.app` 名，另立项 |
| G-4 | IPv6 不做完整支持（`splitHostPort` 按最后一个冒号拆端口） | 不能填裸 IPv6 | 需要时再加括号字面量 |
| G-5 | 远端浏览是「输入路径 → 列一层 → 点一项」，不是树 | 深层目录要多次点 | 可循环列出或接 `sftp` |
| G-6 | 直拷依赖源机 `rsync` 且源机能 ssh 到目标 | 缺工具时失败 | 失败后提供「经本机中转」一键 |
| G-7 | `copy.hosts` 预设在窗口里几乎不展示 | 配置段易让人以为有下拉主机表 | 接到互拷 UI，或文档标明仅预留 |
| G-8 | 成功关窗用 `osascript` 关 Terminal 前窗 | 若焦点不在该窗可能关错 | 用窗口 id 或改用 `exit` 后由 Terminal 设置关窗 |
| G-9 | 单文件 1200+ 行、无模块边界 | **已部分解决**：纯逻辑拆到 `Core.swift`；`main.swift` 仍是单文件 UI | 若 UI 继续膨胀，再按启动/互拷拆视图 |
| G-10 | 窗口无滚动视图，目录多时高度溢出屏幕 | 几十个项目时底部按钮不可见 | 套 `NSScrollView` |
| G-11 | 联想菜单每敲一键就 `popUp`，且 `sshHostsCache` 首次加载后不刷新 | 连续输入易被打断；改 `~/.ssh/config` 需重启应用 | 只在停顿后弹出 + 按文件 mtime 失效缓存 |
| G-12 | `launchInTerminal` 的 PATH 写死 `~/.bun/bin`、`/opt/homebrew/bin` | 别的机器找不到工具 | 抽成配置项或读登录 shell 环境 |
| G-13 | 无 LICENSE / 版本号 / changelog | 对外分发与回溯困难 | 需要发布时补 |

## 本轮修复记录（2026-10-29）

| 问题 | 处理 |
|------|------|
| `parseConnection` 把 `IP:端口` 解析成 `IP + 用户名` | 主机在前分支遇到「冒号 + 纯数字」转交 `splitHostPort`，测试覆盖回归 |
| rsync/scp 不支持 `user@host:port:path` | 新增 `splitRemoteSpec`，端口转 `-e "ssh -p N"` / `scp -P N`，含双远端直拷 |
| `sshListDir` 管道先 wait 后读，大目录死锁 | 改为先读完管道再 `waitUntilExit` |
| 自测与解析日志写明文密码/连接串 | 新增 `maskSecret`，日志只记 user/host/port 与密码是否存在 |
| 浏览远端在主线程跑 ssh，最长卡死 8 秒 | 改后台队列 + 状态提示 + 防重入 |
| 默认路径 `~` 被单引号包住，远端 `ls` 报错 | 新增 `remotePathArg`（`~` 裸写） |
| 刷新清空已填的互拷表单 | `refresh` 前后快照/恢复表单 |
| 缺省配置写死本机路径（G-2） | 改占位值，并加断言防回归 |
| 死配置字段 `defaultDirection`/`auth` | 从结构体、缺省配置、示例中移除；旧配置仍兼容 |
| `buildCopyCommand` 内部调 `hasRsync()`（有副作用） | 改为参数 `rsyncAvailable`，调用方探测一次 |
| scp 降级静默丢断点续传 | 状态栏明确提示 |
| `build.sh` 只在首次拷 Info.plist、`pkill -f` 易误杀 | 每次覆盖 plist；`pgrep/pkill -x` 精确匹配 |
| 单文件无模块边界（G-9） | 纯逻辑拆 `src/Core.swift`，UI 留 `main.swift` |
